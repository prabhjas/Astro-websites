DROP FOLDER — licence QR codes and licence PDFs
================================================

Put files here. Tell Claude/Aaron they have landed and they get moved into
each site and published. Nothing in this folder is served to the public.

QR CODES — name them exactly like this:
    kinzahr-qr.png          (or .jpg / .svg)
    cuae-qr.png
    cbss-qr.png
    spheavyrental-qr.png

  cbss-qr and cuae-qr are the SAME licence (CONNECT BUSINESS SUPPORT
  SERVICES L.L.C, 1322500) — one file for both is fine, name it cuae-qr.

LICENCE PDFs — name them exactly like this:
    kinzahr-licence.pdf
    cuae-licence.pdf
    cbss-licence.pdf

  Once a PDF is in place, a "Click here to view the license" button appears
  automatically on that site. Until then the button stays hidden, so there
  is never a broken link.

NOTE: eormiddleast.com has no licence — it is a brand, not a licensed
entity — so it needs nothing here.
